## 💎 Key Features

### 1. 3D Masterpiece Centerpiece (Three.js / WebGL)
- **Physically Based Rendering (PBR)**: Realistic Grade 5 Titanium chassis materials with micro-chamfered edges, antenna separators, and Corning® Gorilla® Armor anti-reflective glass.
- **Interactive 360° Turntable**: Orbit, zoom, and pitch with inertia damping and mobile touch gesture support.
- **Dynamic Camera Exploded View**: Separates the 200MP Wide, 50MP 5x Periscope Folded Tetraprism, 50MP 3x, and 50MP Ultra-Wide lens elements along the Z-axis in real time.
- **Detachable S-Pen Stylus**: Modeled S-Pen slides and rotates out of its silo with low-latency responsiveness.
- **Snapdragon® 8 Elite X-Ray Core**: Crystalline backplate mode revealing copper vapor chamber cooling and glowing neural engine circuits.

### 2. Titanium Atelier (Live Color Studio)
- Seamless real-time material swapping across all 5 authentic finishes:
  - **Titanium Silver Shadow**
  - **Titanium Gray**
  - **Titanium Black**
  - **Titanium Jade Green** *(Exclusive)*
  - **Titanium Pink Gold** *(Exclusive)*

### 3. Interactive Galaxy AI Suite
- **Circle to Search with Google**: Interactive canvas where users draw on an on-screen subject to trigger instant Google AI visual search results.
- **Generative Photo Edit**: Interactive split-slider demonstrating AI generative fill and unwanted object removal.
- **Live Call & Voice Interpreter**: Dual-channel conversational translation with simulated voice waveforms.
- **AI Note Assist**: One-touch conversion of messy handwriting into structured executive summaries.

### 4. Dynamic Cart & Official Samsung Store Transfer
- Live storage selection (256GB / 512GB / 1TB).
- Interactive trade-in calculator (up to \$800 instant credit).
- Galaxy ecosystem bundles (Galaxy Buds3 Pro, Galaxy Watch Ultra, S-Pen Pro).
- Transparent financing calculation (\$36.11/mo at 0% APR).
- **Official Store Transfer Flow**: Clicking checkout opens an authentic Samsung synchronization modal that transfers the configuration and safely redirects to the [Official Samsung Store](https://www.samsung.com/us/smartphones/galaxy-s25-ultra/buy/).

### 5. Procedural Sound Design
- Synthesized Web Audio API sound effects (metallic haptics, dual camera shutter, futuristic AI chime, S-Pen eject) with a global mute toggle.

## 🛠️ Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **3D Engine**: Three.js (Procedural geometries, PBR Shaders, ACESFilmic Tone Mapping)
- **Styling**: Tailwind CSS + Glassmorphism + Dynamic Radial Meshes
- **Icons**: Lucide React
- **Celebration**: Canvas-Confetti
- **Audio**: Web Audio API Procedural Synthesizer
- **Deployment**: Vercel & GitHub Actions

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/viswakpullepu/samsung-galaxy-s25-ultra.git

# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
